# CONTRABEAN
Juego de peleas enfocado a mortal kombat

Acciones que tendra:
- Movimiento de izquierda a derecha
- Salto
- Golpes
- Patada
- hadouken

Limitaciones que tendra: 
- Solo tendra dos personajes
- No tendra finales
- No tendra mas escenarios

Las librerias que se usaron son:
- pygame
- sys
- subprocess 
- os
- math
- ParticleSystem

El programa se hizo en python 3.13.2

Se creo el menu y el juego, la unica funcion del menu es llevarte al juego base llamado contrabean, el juego es de peleas de jugador contra jugador, el objetivo es empujar al otro fuera de la pantalla para asi ganar puntos, el juego es infinito, no tiene fin, el juego se puede reiniciar y te puedes ir al menu estando en el juego.

- R: Reiniciar
- T: Menu

Controles:

Jugador1
- A #Izquierda
- W #Salto
- D #Derecha
- B #Golpe
- N #Patada
- M #Haduken

Jugador2
- 🡠 #Izquierda
- 🡡 #Salto
- 🡢 #Derecha
- kp1 #Golpe
- kp2 #Patada
- kp3 #Haduken
